# Sicurezza

Non pubblicare vulnerabilità o credenziali in una issue pubblica.

Per segnalazioni di sicurezza usa la funzione **Report a vulnerability** di GitHub, se disponibile nel repository, oppure contatta privatamente il proprietario del repository tramite il suo profilo GitHub.

Il progetto non richiede token, password o chiavi API nel browser degli utenti. Non inserire segreti nei file, nei commit o nel calendario pubblico.
