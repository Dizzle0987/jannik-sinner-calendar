# Contribuire

Grazie per l’interesse verso Jannik Sinner Calendar.

## Segnalazioni sui dati

Una correzione relativa a partita, orario, campo, risultato o copertura televisiva deve includere un collegamento a una fonte ufficiale e specifica. Non sono accettate indiscrezioni, previsioni, turni non ancora raggiunti o informazioni dedotte dai soli diritti generali di un’emittente.

## Modifiche al codice

1. descrivi chiaramente il problema;
2. mantieni un solo calendario pubblico `calendar.ics`;
3. non inserire credenziali o dati personali;
4. conserva UID stabili per gli eventi esistenti;
5. verifica il sito su schermi desktop e mobili;
6. controlla che il file iCalendar inizi con `BEGIN:VCALENDAR` e termini con `END:VCALENDAR`.

Apri una pull request piccola e focalizzata, spiegando le fonti utilizzate e il comportamento modificato.
